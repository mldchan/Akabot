
# REPOSITORY HAS MOVED!

The repository now resides [here](https://git.lunya.pet/Lunya/Akabot).

## Why?

The bot is aiming for only using FOSS (Free and Open Source Software) and GitHub is not a FOSS product. We are using our own self-hosted solution for Git since last year and it's been going great, if not better, than GitHub.

## How do I contribute now?

You can sign in on my Forgejo instance with a GitHub account. This will make my Forgejo instance use your GitHub username and e-mail. Then, you can fork the repository just like usual and make changes to it.
